WebStorm Run Configs & Guidelines

.idea/ + .junie/

Opening this repository in JetBrains WebStorm immediately surfaces two 1-click run targets and our persistent Junie engineering rules:

  • .idea/runConfigurations/C9_DraftForge_Dev_Server.xml — launches our zero-build Node static ESM server at http://127.0.0.1:4173.
  • .idea/runConfigurations/Run_Draft_and_Macro_Tests.xml — executes npm test (node --test test/*.test.js) inside WebStorm's native Test Runner tool window.
  • .junie/guidelines.md — enforces pure deterministic functions, zero runtime npm dependencies, JSDoc typing, and mandatory npm test verification.
  • .junie/tasks/fearless-squeeze-spec.md — exact input/output contract used to drive Junie's red-green TDD sprint with zero ambiguity.
